# Memory-Fragmentation-and-Compaction-Simulator
## Technologies

- HTML, CSS, and JavaScript for the interface and visualization
- Python for the local JSON API, memory state, and allocation algorithms

## Project structure

```text
index.html                 Page structure and controls
style.css                  Visual design and responsive styles
script.js                  Browser behavior and rendering
backend/
  allocation.py            First-fit, best-fit, and worst-fit allocation
  compaction.py             Process relocation during compaction
  fragmentation.py          Free-hole detection and statistics
  memory.py                 Memory manager and process state
  process.py                Process data model
  server.py                 Local HTTP server and JSON API
```
